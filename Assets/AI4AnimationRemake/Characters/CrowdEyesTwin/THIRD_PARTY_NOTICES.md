# MPFB Basketball Player Assets

The character is an original synthetic athlete generated with MPFB 2.0.16. It is not an NBA player likeness and does not contain NBA 2K assets.

## Sources and licenses

- MPFB: MakeHuman Community, GPL/AGPL code used as a Blender generation tool. The tool code is not redistributed in the Unity build.
- MakeHuman system assets: MakeHuman Community, CC0. Used for the human base, skin, eyes, teeth and hair.
- `elvs_male_athletic_tank1`: Elvaerwyn, CC BY. Source: MakeHuman Community `shirts03` asset pack.
- `elvs_male_swim_shorts1`: Elvaerwyn, CC BY. Source: MakeHuman Community `pants03` asset pack.
- `punkduck_running_shoes_01`: punkduck, CC BY. Source: MakeHuman Community `shoes02` asset pack.
